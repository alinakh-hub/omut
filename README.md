# Омут памяти

Дневник снов с поиском похожих записей при дежавю. Одна страница, без серверов и регистрации.

- Сны записываются текстом или голосом (кнопка микрофона в поле).
- Время записи фиксируется при сохранении, текст потом не меняется.
- Всё хранится в браузере на устройстве. Данные никуда не отправляются.
- Поиск пока по совпадающим словам. Поиск по смыслу появится в следующей версии.
