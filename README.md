# Омут памяти

Дневник снов с поиском похожих записей при дежавю. Одна страница, без серверов и регистрации.

- Сны записываются текстом или голосом (кнопка микрофона в поле).
- Время записи фиксируется при сохранении, текст потом не меняется.
- Всё хранится в браузере на устройстве. Данные никуда не отправляются.
- Поиск пока по совпадающим словам. Поиск по смыслу появится в следующей версии.

## Как опубликовать

1. Загрузите файл `index.html` в корень репозитория (Add file → Upload files).
2. Откройте Settings → Pages. В поле Source выберите Deploy from a branch, ветку `main` и папку `/ (root)`.
3. Через минуту-две страница появится по адресу `https://alinakh-hub.github.io/omut/`.
4. Откройте адрес на телефоне. В Chrome выберите «Добавить на главный экран», в Safari «Поделиться → На экран Домой».

Голосовой ввод работает только по https. GitHub Pages даёт https автоматически. При первом нажатии на микрофон браузер спросит разрешение.
